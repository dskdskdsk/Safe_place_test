# Safe Place 72.3 — Етап C

База: прийнятий Stage B 0c52397d9349a2196f6cb6f53b55ea9493dcb133.
Специфікація: IMPLEMENTATION_PLAN.md, розділи 4 та 6. Аудит legacy збережений як історичний документ.

## Результат і межі

Додано чистий API `readInsightCandidates(snapshot, period, anchor, asOf)`.
Він повертає докази для майбутнього відбору карток D; поточний UI його ще не викликає.
Візуально модуль Настрій залишається як у B. Довгий розділ B поки лишається згорнутим;
остаточне скорочення й перенесення деталей разом із короткими картками — D.
Це не готова нова система користувацьких текстів, не аналіз тексту/голосу та не AI.

## Контракт

- week/month: рівно 84 календарні дні до min(кінця вибраного періоду, asOf), включно.
- year: вибраний календарний рік до цієї межі; повністю майбутній період порожній.
- all: план не визначає вікно зв'язків; порожні кандидати з явною причиною `all-time-associations-not-specified`.
- Звичка A — відмітка; B — спостережуваний день без відмітки. Чисті чернетки/порожні days виключені.
  Початок обмежено першою реальною відміткою не пізніше cutoff; це не дата створення.
  Збережені відмітки без визначення звички читаються за ID, видалені дані не реконструюються.
- Статуси порівнюються тільки з іншими відомими статусами; емоції — з днями з іншими емоціями.
- Кожен оцінений день має одну вагу. Для кожної групи повертаються середня, n,
  знаменник спостережуваних днів, покриття, дати всіх і оцінених днів. Пропуски не заповнюються.
- Тижні пн–нд не перекриваються; крайні відрізки обрізані до вікна/першої відмітки та позначені partial.
  У localDelta входять тільки тижні з оцінками обох груп, вага nA*nB/(nA+nB).
- Рівень 1 — факти; рівень 2 — мінімум 5 оцінених днів у кожній групі.
  Рівень 3 — 10/10, K≥6, однаковий ненульовий знак загальної й локальної різниці,
  обидва модулі ≥0.7, 3*support≥2*K, 5*opposite≤K. Нейтральні тижні входять до K.
  Для порогів 0.3 і 0.7 допускається лише похибка floating point 1e-12.
- Контекст: статус, пн–пт/сб–нд, спільні підгрупи; для аналізу статусу лише тип дня.
  Підгрупи мають nA≥2,nB≥2. Повертаються числа/дати кожної, зважена різниця та
  охоплення A/B окремо для оцінених і всіх віднесених до групи днів.
- Переворот знаку в будь-якій придатній підгрупі позначається як суперечність.
  Нуль/брак даних не є успішною перевіркою. Частковий результат зберігається навіть нижче 50%.
  `level` відбиває числову повторюваність; `interpretation` окремо вказує контекстну
  суперечність/невизначеність. `generalInterpretationAllowed` дозволяється тільки для рівня 3
  з повністю охопленими й узгодженими перевірками. Часткові докази залишаються доступними
  для формулювань D лише про включені контексти; вони не приховуються.
- Жодного persist, DOM, Date.now, Math.random або глобального кешу. Результати нові, детерміновані,
  з обмеженнями щодо причинності, множинних перевірок і залежності сусідніх днів.

## Перевірки

`tests/insight_c.py`: граничні синтетичні приклади та незалежний Python oracle
на фіксованому seed 723; випадкові набори з 12 звичками, пропусками, нерівним покриттям,
окремим і спільним контекстом. Результати — tests/artifacts/insight-c/results.json.
Результат випадкових тестів не означає гарантованої відсутності хибних зв'язків.

Цільові приклади: частота 1–7/7, порожня B, 5 підтримок +2 нейтральні тижні,
від'ємний напрямок, точні межі ±0.3/0.7/2⁄3/20%, 4/5 та 9/10 оцінених днів,
тренд часу без локального зв'язку, переворот знаку, неперевірений контекст,
часткове покриття <50%, історичне вікно, майбутнє, редагування/видалення,
заморожений вхід, заборонені побічні виклики, відокремлений вихід, три часові пояси.

Регресія: tests/insight_a.py, tests/insight_b.py та tests/preview721.py.

це зафіксовано, пороги під ці дані не змінювалися.
