# 71.1 — Глина й папір

## Джерела, перевірені 27.10.2026

- [Claude](https://claude.com/) та його [основний CSS](https://claude.com/_next/static/chunks/4682c15f1297a6b0.css).
- [Офіційна палітра Anthropic у публічному репозиторії](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md).
- [Anthropic](https://www.anthropic.com/) — додатковий контекст. Цільова палітра взята з CSS Claude, не з припущення про точний вигляд усіх продуктів Anthropic.

У CSS Claude підтверджено нейтральні #faf9f5, #f5f4ed, #f0eee6, #e8e6dc та акцент clay #d97757. Публічна бренд-палітра Anthropic також містить #faf9f5 і #d97757. Це дослідження публічних матеріалів; приватний інтерфейс Claude після входу не перевірявся.

## Що змінилося

У 71.0 бірюзові заливки записів і активних вкладок переважали над паперовою основою. Для бажаного автором пастельного характеру 71.1 використовує близькі білі нейтралі, глину у невеликих акцентах і менш помітні межі поверхонь.

| Роль | 71.1 | Обґрунтування |
|---|---|---|
| Фон | rgb(250 249 245) | Теплий потертий білий з палітри Claude |
| Картка | rgb(255 254 251) | Трохи світліший папір, адаптація для щоденника |
| Поля / записи | rgb(245 244 237) | М’яка поверхня без темно-бежевого відтінку |
| Другий рівень | rgb(240 238 230) | Делікатне розділення блоків |
| Декоративна глина | rgb(217 119 87) | Вихідний акцент Claude |
| Акцентний текст | rgb(163 78 51) | Темніший для читання малого тексту |
| Основна кнопка | rgb(182 85 54) | Темніший варіант під світлий підпис |

Текстові й голосові записи світлі, з темним текстом і тонкою глиняною рискою. Активні вкладки пастельні. Скасування виключення з дайджесту, редагування, підтвердження видалення та голосові контролі залишаються помітними. Штучний шум/текстура, зовнішні шрифти та нові продуктові блоки не додані. Системний шрифт зберігає український набір і роботу офлайн.

Компонентні правила обмежені світлою темою. Темні компоненти порівнюються з v71.0 автоматично. Колір оболонки браузера/PWA синхронізований із поточною темою; світлий фон запуску PWA відповідає паперовій палітрі. Іконки застосунку не перероблялися.
