# 75.0 Adaptive spacing

Плавні відступи: 375 px — 16/14 px, 400 px — 18/15 px, від 425 px — 20/16 px (внутрішній відступ / проміжок карток). На менших екранах значення обмежені мінімумом. Системний шрифт збережено. У світлій темі додано м’яку двошарову тінь карток.

Перевірки Chromium:
- `python tests/spacing75.py`: PASS — 320/375/390/400/430/440 px, дві теми, чотири екрани, шрифт кореня 16 і 20 px, без горизонтального переповнення.
- `python tests/edit731.py`: PASS — 5 груп редагування та мобільного вигляду.
- `python tests/collapse731.py`: PASS — стан модулів, мова й тема після перезавантаження.
- `python tests/mobile.py`: PASS — клавіатура, фокус і модальні вікна.

Це браузерна емуляція. Відчуття відступів і тіней слід оцінити на фізичному iPhone. Зміна не є заявою про повну відповідність WCAG: компактні допоміжні кнопки з попередніх версій не перероблено.
