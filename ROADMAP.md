# Подальший план після 70.5

1. **Прийняти 70.5 на iPhone.** Реальний імпорт користувацького архіву, відновлення чернетки, Safari + встановлена PWA, клавіатура, копіювання/вставлення, мікрофон і Files. Уточнити підтримку Web Locks у фактичному середовищі. За дефектів — точкова 70.5.x до нових фіч.
2. **70.6 — щоденний сценарій.** Переривання голосового запису/відмови дозволів, зміна дня й північ, редагування оцінок/емоцій, великі архіви та навантаження на пам’ять. Окремо перевірити порожні/часткові медіа й повторні імпорти.
3. **70.7 — CSS та доступність.** Дублікати стилів, розміри тексту й тач-таргетів, фокус, контраст обох тем, довгі українські написи. Світлу тему полірувати без нових блоків і без масштабного переписування за один раз.
4. **Після стабілізації — PWA/Capacitor.** Перевірена стратегія оновлення кешу, контроль версії, міграція браузер → застосунок через backup, нативні дозволи/файли, окрема оцінка шифрування й PIN, приватність Gemini та вимоги App Store. Розділення single-file коду — окремий етап із регресійними тестами.

Кожна версія: короткий план → точкові правки → тести → changelog і тег → тестовий деплой. Виправлення втрати даних мають пріоритет над редизайном.
