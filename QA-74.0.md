# 74.0 Media/Recommendations

База: 0cdbea5 (73.0). Гілка: preview/74.0-media-recommendations.

## Реалізація

Спільні читачі media74Rows/media74Latest повертають відокремлені рядки без мутацій, обмежені календарним cutoff. progress читається як active; planned залишається запланованим. Нові твори мають mediaId, денні записи — entryId. Продовження додає новий запис зі сталим mediaId, попередній статус лишається історичним. Новий цикл після завершення отримує новий ID.

startRecommendation додає медіа на поточну місцеву дату незалежно від відкритого дня. Рекомендація зберігає mediaId і startedDate. Статус рекомендації обчислюється з останнього пов’язаного запису. Старі done-рекомендації зберігаються в історії. Видалення не каскадне; якщо всі пов’язані медіазаписи видалені, є дія повернення рекомендації в очікування.

media74Commit спочатку зберігає поточні чернетки, потім виконує єдине збереження змін днів; при невдачі відновлює стан до операції. Undo діє 12 секунд і не перезаписує подальші зміни. Успіх показується лише після запису. Діалог можливих збігів не об’єднує записи автоматично.

Медіа дашборду показує «Зараз / Історія», групи станів, завершення за місяць/рік/весь час, зірки, розгортання вражень. Рекомендації мають категорії очікування та згорнуту історію. Довгі назви розгортаються натисканням. Великі категорії рекомендацій мають обмежену висоту з прокруткою замість старої пагінації. Дві картки використовують спільні стилі та центральні UK/EN тексти.

Старі записи без ID залишаються окремими: ретроспективно неможливо надійно визначити, чи однакові назви позначають один твір або повторний цикл. Явне продовження/вибір існуючого запису надає йому ID без зміни його історичного статусу. Повний JSON/ZIP зберігає всі зв’язки. Експорт частини дат може не містити іншого кінця зв’язку; рекомендація лишається доступною, відсутній зв’язок не створює вигаданих медіа.

## Приймання на iPhone

1. Почати книжку/фільм/гру/прослуховування з рекомендацій; перевірити «Показати» та «Скасувати».
2. Поставити на паузу, продовжити, завершити, додати зірки й враження; звірити «Зараз / Історія» та стан рекомендації.
3. Додати медіа наступного дня: попередній запис зберігає статус, дашборд показує один пов’язаний твір.
4. Перевірити «Почати знову», можливий збіг назви, видалення та повернення рекомендації в очікування.
5. Повторити UK/EN, light/dark, Safari/PWA; перевірити довгі назви, меню, клавіатуру й прокрутку.
