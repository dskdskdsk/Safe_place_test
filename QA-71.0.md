# 71.0 — Читабельність і адаптивність тем

Зміни стосуються оформлення, CSS і стилів у шаблонах. Сховища, імпорт, PIN, Web Locks та контролер visualViewport не змінені.

## Перевірки

- 9 цільових сценаріїв збереження/відновлення: PASS.
- 22 регресійні сценарії: PASS з повтором двох сценаріїв (preferences, unsent_draft), що спершу завершилися на 5-секундному таймауті завантаження. Повтор без змін застосунку пройшов.
- Мобільний набір: PASS — імітація клавіатури, модалки, фокус, PIN, прокручування.
- Синтаксис усіх inline scripts через Node та git diff --check: PASS.

- Дизайн: 16/16 конфігурацій PASS — 375×667, 390×844, 393×852, 402×874, 414×896, 430×932, 440×956, 844×390, кожна у світлій і темній темах. Чотири вкладки без горизонтального переповнення; довгі записи/назви, видимість touch-дій, кнопки записів 44 px, валідний clamp, root 20 px для Today/Notes/Settings.
- Візуально переглянуто знімки 375 px для світлої/темної тем, календаря та дашборда.

## Контраст (розрахунок sRGB)

- Світла тема: приглушений текст / картка 5.68:1; підказка / поле 4.82:1.
- Темна тема: другорядний текст / картка 7.45:1; приглушений текст / картка 5.86:1; білий текст / основна заливка 6.73:1.
- Це перевірка зазначених базових пар, не сертифікація всіх кольорових станів, прозоростей або градієнтів.

## Межі

Chromium/Playwright із синтетичними даними. Реальні iPhone, Safari/WebKit, Dynamic Type, системна клавіатура, Files і мікрофон не перевірені цим релізом. Розмір root 20 px у тесті не еквівалентний системному масштабуванню iOS. Особисті записи користувача не використовувалися.
